# Acceptance criteria
1. A parent page for release 1.0 exists in the ADP space with the documents the chosen risk level requires.
2. Each document is a copy of the current template, filled in place; nothing is rebuilt from text.
3. The risk level and solution type are stated, with the reasoning, as assumptions for a person to confirm.
4. Signature and approval blocks are left empty. Entries a person must supply say TBD.
5. Every page says DRAFT until a person has reviewed it.
